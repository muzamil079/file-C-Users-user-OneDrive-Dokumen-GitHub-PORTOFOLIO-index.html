Backend service yang menyediakan endpoint RESTful API terpusat untuk melayani kebutuhan autentikasi dan pertukaran data secara aman dan konsisten pada aplikasi mobile.

Sistem Informasi Inventaris Barang

Aplikasi web pengelolaan inventaris, kategori, mutasi stok, dan pencatatan transaksi

Ringkasan Proyek

Aplikasi web berbasis Laravel dan MySQL untuk manajemen inventaris barang secara terpadu, mencakup sistem login, pengelolaan barang dan kategori, mutasi stok otomatis, serta rekap transaksi.

Masalah

Pencatatan barang secara manual rentan terhadap selisih jumlah stok, riwayat transaksi yang tidak terlacak, dan ketiadaan pembatasan hak akses sistem.

Solusi

Mengembangkan sistem inventaris dengan autentikasi, relasi basis data antar barang-kategori-transaksi, dan pembaruan jumlah stok secara otomatis pada setiap mutasi.

Fitur yang Dikembangkan

  • Autentikasi Pengguna: Fitur login untuk melindungi hak akses pengelolaan data inventaris.
  • Manajemen Barang & Kategori: Operasi CRUD lengkap dengan relasi data terstruktur.
  • Sinkronisasi Stok Otomatis: Penambahan atau pengurangan stok secara otomatis saat transaksi dicatat.
  • Riwayat Mutasi & Transaksi: Pencatatan log transaksi inventaris secara transparan.
